# AI-ChatBot
💬 Fast AI Chatbot (Tkinter + Ollama)  This project is a desktop AI chatbot built using Python’s Tkinter GUI and powered by Ollama. It delivers real-time streaming responses, similar to ChatGPT, while running entirely locally on your machine.

🚀 Features
⚡ Real-time streaming responses
🧠 Context-aware conversation memory
🖥️ Clean dark-mode UI (Tkinter)
🔄 Multi-threaded for smooth performance
📦 Runs locally (no API key required)
🎯 Optimized for speed (low latency)
